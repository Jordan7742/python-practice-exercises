# Python Practice Exercises

A collection of short Python scripts written while learning the
language — each one is a self-contained exercise covering a different
core concept: conditionals, loops, functions, string manipulation,
dictionaries, and basic file I/O.

| File | What it covers |
|---|---|
| `typing_speed_calculator.py` | Dictionaries, string iteration |
| `username_generator.py` | String slicing/concatenation |
| `salary_bonus_calculator.py` | Conditionals, type casting |
| `initials_generator.py` | String indexing |
| `number_negator.py` | Basic arithmetic |
| `cycling_water_calculator.py` | `math` module, floor division |
| `quarter_of_year.py` | Chained conditionals |
| `teddy_bear_pay_calculator.py` | Comparing calculated values |
| `average_attendance.py` | Nested lists, generator expressions |
| `secure_string_validator.py` | Multi-condition validation, helper functions |
| `digit_mode_finder.py` | `statistics` module |
| `simple_calculator.py` | Functions as branching logic |
| `cinema_ticket_price.py` | Functions with return values |
| `rollercoaster_height_checker.py` | `while` loops, compound conditions |
| `shop_tax_calculator.py` | Nested data structures, file writing |
| `people_counter.py` | State tracking, input loops |

## Running any of them

```bash
python <filename>.py
```

Each script runs standalone and prompts for input in the terminal.

## Note on this repo

These were written early on as individual practice exercises rather
than one larger project — they're grouped here (and lightly cleaned up
from their original drafts) rather than split into separate repos,
since each one is only a few lines long. For a larger, structured
project, see my [Macro Tracker](#) and other project repos.
